# Personal Portfolio Website

A responsive personal portfolio website created for SWE 363: Web Engineering and Development.

The portfolio introduces me as a Software Engineering student with a concentration in Cloud Computing and presents selected academic projects, contact information, and an interactive light/dark theme.

## Features

- About Me section
- Academic projects showcase
- Contact section and form
- Responsive design for desktop, tablet, and mobile devices
- Sticky navigation bar
- Light and dark theme toggle
- Accessible labels and descriptive image alternative text

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Running the Project Locally

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using a browser, or use the Live Server extension in Visual Studio Code.
4. Navigate through the About Me, Projects, and Contact sections.
5. Use the theme toggle button in the header to switch between light and dark modes.
